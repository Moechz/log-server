# Security policy

Please do **not** open a public issue containing credentials, tokens, private keys, customer logs or
deployment details.

Use GitHub's **Report a vulnerability** (Security Advisories) for this repository, or contact the
maintainer through the repository profile.

When reporting, include the version (`dpkg-query -W log-server-for-tos`), TOS version, architecture and a
minimal reproduction. Redact all secrets and personal data.
